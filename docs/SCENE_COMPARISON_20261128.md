日期：2026-11-28。便携对照页在独立工程的 `artifacts/scene-comparison-20261128/compare.html`。双击用浏览器打开；移动时保留整个文件夹。左为原版，右为 Godot，可切地图及片段、分别拖动进度、共同以 1× 播放。共同播放只从各自当前位置继续，不代表帧同步或动画相位配准。页面及九个视频不依赖网络；媒体与大分析目录被 Git 忽略，核心仓库不包含这些本地录像。

## 本次能看到的差异

- 两图码头、船、桥、房屋、植被的主要空间对应关系已可直接比较。无名 Godot 人物后侧有箱桶，原版相应视野未见；需核任务/存档/显隐条件，不能直接认定资产多放或擅删。
- Godot 近水在多个观察时点持续偏亮青蓝，原版底部水更深蓝；Godot 沙地、草与花丛亮部更白亮。后续分水面、直接/环境受光和后期链核对，不以统一压暗或去饱和代替来源分析。
- 两图都有随时间变化的水纹、大块明暗及部分小生物活动。仍未证明全部枝叶摆动、船体摇动、完整粒子随机、天气或全地图动态已还原。
- 游仙近花与远岸的虚化存在差别；机位略偏，不能从本次视频量化精确DOF误差。Godot进出屋可见屋顶/外墙显隐和明暗恢复，游仙窗面很亮，需原版同屋参考后判断。

## 录制方式与检查

新增 `project/scripts/verification/diagnostics/record_normal_speed.gd` 复用现有 FollowDriver 和原角色物理路线，仅移除逐绘制回读与日志。码头采用原默认出生点，房屋只有录像前的一次起点放置，之后连续输入进屋、停留、出屋；不改模型、镜头、time_scale、模拟节奏或安装TLV。四次实际运行完整退出，错误/警告空；两段房屋都恰有两次真实状态转换且支撑检查通过。默认TLV关闭的录像不作为V7优化性能证据。

九个视频已核来源SHA并完整解码；无名原版有效507帧逐帧检查，Godot检查构图样本、门口切换和尾部。机器解码不等于全帧美术验收。播放器JavaScript语法、相对文件引用与模拟事件检查通过。根任务尝试本机浏览器UI验证时，Computer Use因不能可靠确定当前URL而停止；已停止界面操作，未进行实际点击播放验收，也未绕过该限制。浏览器播放兼容性仍待打开确认。
